# 카톡 자동답장 도우미

선택한 방의 카카오톡 알림을 로컬에서 수집하고, 설정한 방에 **Gemma 4 로컬 모델** 기반 AI 자동응답을 연결하는 안드로이드 앱입니다. 대화 내보내기 파일에서 본인을 선택하면 말투를 자동 분석합니다. 모델을 준비한 뒤에는 인터넷 없이도 AI 답장을 생성합니다.

## 핵심 기능

- **Gemma 4 로컬 답장**: LiteRT-LM 기반 Gemma 4 `.litertlm` 모델로 인터넷 없이 AI 답장 생성
- **모델 다운로드**: 로컬 경로에서는 앱 안에서 Gemma 4 E2B LiteRT-LM 모델 다운로드 (~2.58GB)
- **카카오톡 알림 기반**: 알림 리스너로 메시지를 감지하고 PendingIntent로 답장
- **방별 메모**: 각 채팅방별 컨텍스트를 메모로 저장, AI가 답변 시 참고
- **모든 방 모드**: 토글 하나로 모든 채팅방에서 AI 답장 활성화
- **자동 말투 분석**: 방별 내 말투·전체 내 말투·방 분위기를 대화 DB에서 분석
- **선택 수집과 보관**: 최근 90일 보관, 방별 학습 데이터 삭제, 클라우드 백업·기기 이전 제외
- **수동 설정은 선택 사항**: 직접 예문·방별 말투 수정값이 있으면 자동 분석보다 우선 적용
- **자동 대화 요약**: 최근 대화를 자동으로 분석해 메모에 반영
- **강화된 로컬 그라운딩**: primary/style_rewrite/human_style/compact/emergency 프롬프트에서 페르소나, 말투, 방 메모, 최근 대화 맥락을 최대한 유지
- **트리거 조건**: 기본값은 AI 판단이며, 멘션, 질문, 키워드, 모든 메시지 모드는 명시적으로 선택 가능

## 지원 범위

- 지원: Gemma 4 로컬 모델 (`.litertlm`, LiteRT-LM 런타임, CPU 우선)

- 지원: AI 판단형 응답, 멘션 반응, 질문/명령형 반응, 고정 답장

## 빠른 시작

1. `대상 방 관리` 또는 `대화 수집·말투 분석`에서 카카오톡 방 직접 선택을 시작합니다. 처음에는 시스템 설정에서 `카카오톡 방 직접 선택` 접근성 서비스를 직접 켭니다.
2. 선택을 시작한 뒤 2분 안에 카카오톡에서 원하는 대화방을 열고 화면 위의 `현재 방 선택` 버튼을 누릅니다. 앱으로 돌아와 방 이름을 확인해야 등록됩니다. 이미 열린 방도 선택할 수 있고 기존 알림이나 대화 파일은 필요하지 않습니다. **이름이 같은 방은 구분할 수 없으므로**, 사용 전에 카카오톡 방 이름을 다르게 설정해야 합니다.
3. 이후 수신 메시지를 저장하려면 알림 접근 권한을 허용하고 대화 수집 화면에서 `수집 시작`을 확인합니다. 방 선택이나 수집 시작만으로 AI 자동답장은 켜지지 않습니다.
4. 과거 대화나 직접 보낸 내 말투를 분석하려면 `과거 대화 파일 가져오기`로 카카오톡을 열고, 대화방의 **대화 내보내기 → 공유**에서 자동응답기 앱을 선택합니다. Android 카카오톡 UTF-8 `.txt`, 최대 10 MiB를 지원하며 방별로 파일을 한 번에 하나씩 공유합니다. 참여자 중 본인을 고른 뒤 저장할 방을 확인하고, 동명이인·외부 자동답장이 섞인 파일은 먼저 정리합니다.
5. 말투 미리보기에서 표본 수·분석 기간·갱신 시각을 확인합니다. 최근 90일 중 분석 가능한 발화가 12개 이상이면 적용합니다.
6. `AI 답장 설정`에서 모델을 준비하고 응답할 방·발화자 조건·트리거를 확인한 뒤 `AI 자동 답장`을 켭니다. 직접 적는 예문·말투는 선택 사항입니다.

알림에서는 주로 상대방의 수신 메시지를 확보합니다. **카카오톡에서 직접 보낸 내 발화를 계속 자동 수집하는 기능은 없습니다.** 내 말투를 최신화하려면 파일을 다시 가져오세요. 같은 파일을 같은 방에 가져오면 중복은 건너뜁니다. 앱이 기록으로 확인한 AI 답장은 분석에서 제외하지만, 내보내기 파일만으로 모든 자동답장을 식별할 수는 없습니다.

수집 OFF는 이후 저장을 중단합니다. 이미 저장한 원문·예문·자동 분석은 `학습 데이터 삭제`로 함께 지울 수 있습니다. 자동답장 OFF는 답장만 중단하며 수집을 켠 방의 저장은 계속됩니다. 데이터는 클라우드 백업·기기 이전 대상에서 제외됩니다. 90일 정리는 앱 실행·DB 접근·백그라운드 작업 시 수행하므로, 기기나 앱이 오래 중지된 경우 다음 실행까지 지연될 수 있습니다.

## 모델

앱은 **Gemma-4-E2B-it-LiteRT-LM** 로컬 모델만 사용합니다. 이전 버전에서 저장된 OpenAI 설정이 남아 있어도 실행 시 자동으로 로컬 Gemma 설정으로 정리됩니다.

| 모델 | 크기 | 한국어 | 비고 |
| --- | --- | --- | --- |
| Gemma 4 E2B LiteRT-LM | ~2.58GB | 좋음 | 기본값, Gemma 4 경로 |
| Qwen3 0.6B LiteRT | ~614MB | 기본 수준 | 공개 테스트/회귀 검증용 |
| Gemma 3 1B LiteRT | ~555MB | 양호 | Gemma 계열 테스트 대안 |

모델은 앱 내 다운로드 기능으로 받을 수 있으며, LiteRT-LM 호환 `.litertlm` 파일을 직접 추가할 수도 있습니다.

## 성능 가이드

- 기본 Gemma 4 E2B 모델은 저장 공간보다 **한국어 품질과 답변 자연스러움**을 우선합니다.
- compact/emergency 재시도에서도 페르소나, 말투, 방 메모, 최근 대화를 일부라도 유지해 답장 맥락 손실을 줄입니다.
- 테스트와 회귀 검증에는 더 작은 LiteRT-LM 공개 모델을 사용해 다운로드 시간과 저장공간 부담을 줄입니다.
- 실제 기기 성능은 기기 RAM/CPU와 모델 크기에 따라 크게 달라집니다.
- Gemma 4 LiteRT-LM 경로는 **실제 ARM64 Android 기기**에서만 검증 대상으로 취급하며, 현재 에뮬레이터는 지원하지 않습니다.
- 더 큰 모델일수록 한국어 품질은 좋아질 수 있지만 첫 로딩과 답장 생성은 더 느려집니다.
- 최소 2GB RAM 권장
- 에뮬레이터보다 실제 기기에서 속도가 더 현실적으로 나옵니다.

## 개발

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease
```

- NDK 27 이상 필요 (앱 내 네이티브 컴포넌트 빌드용)
- CMake 3.22 이상 필요
- LiteRT-LM Android SDK를 사용합니다
- 기본 모델은 공개 URL에서 다운로드합니다. `.env`와 환경 변수의 `HF_TOKEN`을 앱에 포함하거나 다운로드 인증에 사용하지 않습니다.

### 방 선택과 대화 수집

사용자가 카카오톡에서 대화방을 열고 `현재 방 선택` 버튼을 누를 때만 접근성 서비스로 상단의 방 이름을 읽습니다. 앱으로 돌아와 확인해야 등록됩니다. 선택은 2분 동안만 유효하며 메시지 내용 수집이나 자동 클릭은 하지 않습니다. 저장한 ID는 이 앱의 로컬 ID이며 카카오톡의 고유 채팅방 ID가 아닙니다. 동명 방은 구분할 수 없습니다. 이후 대화 수집은 수신 알림을 사용하고 과거 대화 파일 가져오기는 별도 선택 사항입니다. [구현 범위와 공식 API 조건](docs/kakao-room-selection.md)을 참고하세요.
